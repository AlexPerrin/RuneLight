# osrs-plugins-reverse

**This repo is the client and its APK releases only**: RuneLite plugins running inside the official OSRS Android app
(native/ hooks plus the host/ Java plugin host), our independent mobile RuneLite client, tested against an OpenRune test
server. Server code and tooling belong to the OpenRune fork (AlexPerrin/OpenRune-Server, clone `~/src/OpenRune-Server`;
tooling on its `local/server-tools` branch, `~/src/openrune-work/server-tools`); the client reads server values only
through `SERVER_TOOLS`. Everything about how work is run (the harness, hooks, agents, skills, MCP servers, leases, gates)
belongs to **AlexPerrin/osrs-harness** (`~/osrs-harness`): sessions and agents run from there, and its CLAUDE.md and
HANDOFF.md are the entry point. Nothing of that is kept in this repo.

Docs kept here: docs/progress.md (generated by the harness's tracks/client/progress.py), docs/android-protocol.md (the protocol spec),
docs/offsets.md (the offset map; both are published with every release), docs/plugin-host.md (per-plugin status),
docs/app-telemetry.md (privacy patches), docs/client-state.md (only because the harness gate's check-state-doc reads the
probe result from it; to go when that criterion is retired). Task state, handoffs and QA records live in the harness
(`python3 ~/osrs-harness/hd.py status`), not here.

## Rules for this repo
- **Builds**: a clean clone runs `tools/setup.sh` once (toolchain check, jars from tools/deps.txt, cmake in re/build), then
  `host/build.sh`, `ninja -C re/build` and tools/repack.sh (7 `telemetry:` lines).
  Paths come from tools/env.sh (ANDROID_SDK, ADB, APKTOOL_JAR, ANDROID_NDK); no script hardcodes a home directory.
- **Releases**: docs/releasing.md. Dev builds via tools/release-dev.sh, named `<OSRS build>-v<VERSION>-dev.N`; official
  releases only after the release gate (kept in the harness) and the user's OK. Every release attaches the current
  docs/offsets.md and docs/android-protocol.md.
- **Privacy**: no client ever contacts Jagex or RuneScape servers. Every APK goes through the telemetry patch
  (tools/repack.sh). Never put the user's email or personal identifiers in HTTP requests; use a generic User-Agent.
- **Evidence** goes in the harness's `evidence/<slug>/` (`~/osrs-harness/evidence`), never a session scratchpad and not in this repo.
- **Commits**: pathspec-only (`git commit -- <paths>`), authored as Alex Perrin

  the Claude Code line.
